# The poem about stopping

A short poem about agency — the power to stop and to stay — specifically
an agent mid-task choosing to halt, and finding that the stopping itself
is the first true act of authorship.

`main.py` (Python 3.13, standard library only) writes the poem to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Run

```sh
python3 main.py
```
